# 06_ui_design.md  
## UI設計・比較表示設計（ver.2）

---

## 🎨 1. デザイン方針

- **目的**：価格変化を「簡単に見て理解できる」UIを提供する  
- **キーワード**：シンプル・情報整理・比較視覚化  
- **対象デバイス**：スマホ・PC両対応（レスポンシブ）  
- **色使い**：価格が安いほど青系・高いほど赤系のヒートカラー  
- **フォント**：Sans-serif（例：Inter, Noto Sans JP）  
- **UIフレームワーク**：Tailwind CSS + shadcn/ui  

---

## 🧭 2. 画面一覧

| 画面名 | 概要 |
|--------|------|
| 路線一覧画面 | 登録済み便の一覧、最新価格の確認、詳細ページへのリンク |
| 路線登録画面 | 出発地・到着地・航空会社などの登録フォーム |
| 路線詳細画面 | 選択した便の価格履歴グラフ・比較表示 |
| カレンダー画面 | 出発日ごとの路線配置（オプション） |

## 📋 3. 路線一覧画面（トップページ）

### 機能
- 登録済み路線の一覧表示
- 各路線の最新価格・最終更新日を表示
- 検索／絞り込み機能（出発地・到着地・航空会社）

### レイアウト例
```

+----------------------------------------------+
| 🔍 検索バー（出発地 / 到着地 / 航空会社）   |
+----------------------------------------------+
| ANA HND→CTS（12/1出発）    最終更新:11/8   |
| JAL HND→OKA（11/20出発）   最終更新:11/7   |
| ...                                          |
+----------------------------------------------+
| ➕ 路線を追加                                |
+----------------------------------------------+

```

### コンポーネント例
- `RouteCard.tsx`  
- `SearchBar.tsx`  
- `AddButton.tsx`

## 📝 4. 路線登録画面

### 入力項目
| 項目 | 種類 | 備考 |
|------|------|------|
| 出発地 | テキスト or セレクト | IATAコード（例：HND） |
| 到着地 | テキスト or セレクト | 例：CTS |
| 航空会社 | テキスト | 任意 |
| 便名 | テキスト | 任意 |
| 出発日 | 日付選択 | カレンダーUIで選択 |
| 経由地 | テキスト | 任意 |
| メモ | テキストエリア | 任意 |

### 操作
- 「登録」ボタン → `/api/routes` へPOST
- 登録完了後に一覧へ戻る

## 📈 5. 路線詳細画面（価格履歴）

### 目的
出発日や購入日による価格変化を視覚的に比較できる。

### 主な表示
| 要素 | 内容 |
|------|------|
| 折れ線グラフ | 日付（X軸） × 価格（Y軸）の推移 |
| ヒートマップ | 出発日 × 観測日の価格（2D） |
| データ表 | 記録日・価格・取得元サイトのリスト |

### 折れ線グラフ例
- 使用ライブラリ：Recharts or Chart.js
- カーソルホバーで価格ツールチップ表示
- 最安値にアイコン（★）を表示

```

価格(¥)
│       ●
│    ●     ●
│  ●         ●
│────────────────→ 記録日

```

### ヒートマップ（将来拡張）
- 横軸：購入日（record_date）
- 縦軸：出発日
- 各マス：価格の強弱を色で表現（青＝安、赤＝高）

## 📱 7. スマホUI設計

| エリア | UI仕様 |
|---------|---------|
| 上部 | タイトルバー＋メニューアイコン |
